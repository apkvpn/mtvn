# Google Play listing template

## App name

Manoto VPN

## Short description

Simple VPN client for managing VLESS and Trojan connections.

## Full description

Manoto VPN helps you import, organize, and connect to VPN configurations from one place. Choose a server, review latency, import a link or QR code, and manage local profiles from a clean interface.

### Features

- VLESS and Trojan configuration support
- QR code, clipboard, and manual link import
- Local profile storage
- Server latency display
- One-tap connect and disconnect
- Connection loading state

**Important:** Connection quality and privacy depend on the VPN endpoint configured by the user. Review the operator and configuration before connecting.
